Faster, more accurate quotes

Tell us exactly which device you have

Send us the make and model of your laptop or server, plus its serial number or service tag, through the form or at info@aibuildapp.net. With that we can look up the exact part that needs replacing and give you a more accurate quote.

1 · Model

System details with msinfo32

Press Windows + R (or open Command Prompt), type the command below and press Enter. Send us the System Manufacturer, System Model and Processor lines, or a screenshot.

msinfo32
2 · Serial / service tag

Find the serial number

In PowerShell:

Get-CimInstance Win32_BIOS | Select-Object SerialNumber

On older Windows versions, in Command Prompt:

wmic bios get serialnumber

On Dell computers this number is the Service Tag. It is also printed on a sticker under the laptop or on the server chassis. Microsoft is removing WMIC from newer Windows 11 versions, so use the PowerShell command if wmic is not recognized.
